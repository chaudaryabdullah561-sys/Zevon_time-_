# Zevon Time

A modern time management website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Animations**: Engaging fade-in animations and hover effects
- **Navigation**: Sticky navbar with smooth scrolling to sections
- **Contact Form**: Functional contact form for user inquiries
- **Modern UI**: Clean and professional design with gradient backgrounds
- **Time Tracking**: Conceptual features for managing time effectively

## Website Sections

1. **Hero Section**: Eye-catching introduction with call-to-action button
2. **About Section**: Information about Zevon Time
3. **Features Section**: Highlights of the application's key features
4. **Contact Section**: Contact form for user inquiries
5. **Navigation**: Sticky header with smooth scrolling

## Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables, flexbox, and grid
- **JavaScript**: Interactive features and animations

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/chaudaryabdullah561-sys/Zevon_time-_.git
   ```

2. Open `index.html` in your web browser
